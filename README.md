# Kick Monitor

[Kick.com](https://kick.com) のチャット参加を自動化するChrome拡張機能です。複数の配信者を監視し、配信開始時に自動でタブを開き、オウムモード・Wスパム検知・ランダムエモート・定型文送信などでチャットに自動参加できます。

---

## 機能一覧

### 📺 配信者モニタリング
ユーザー名を登録するだけで、1分ごとに配信状況を自動チェックします。複数の配信者を同時に監視でき、ポップアップでオンライン／オフライン状態をリアルタイムに確認できます。

### 🔴 配信開始時にタブを自動で開く
監視中の配信者が配信を開始すると、バックグラウンドで新しいタブを自動的に開きます。配信中に何度も開くことはなく、配信開始時に1回だけ開きます。

### 🔁 閉じたタブを再度開く
配信中のタブを手動で閉じた場合、1分以内に自動で再度開きます。パッシブに監視し続けたいストリームに便利です。

### 🦜 オウムモード
チャットのメッセージを15%の確率でランダムに繰り返します。投稿間隔には15〜35秒のクールダウンがあります。直近のチャットメッセージをプールして自然に選択し、ボットのメッセージ・コマンド（`!` / `$`）・Wスパム・UI上の不要テキストはプールに入れないようフィルタリングします。

### 🏆 Wスパム検知
Wスパムのトレンドを検知します。4秒以内に5件以上の「W」メッセージが投稿された場合、自動で参加します。送信するWの長さはチャットの平均に合わせて調整されます。連投防止のため3秒のクールダウンあり。

### 🎭 ランダムグローバルエモート
2〜5分おきにKickのグローバルエモートをランダムに送信します。起動時にKick APIからエモート一覧を取得し、取得に失敗した場合は内蔵のリストにフォールバックします。

### 💬 定型文を自動送信
登録した定型文をランダムに選び、2〜5分おきにチャットへ自動送信します。デフォルトは無効で、定型文を登録してから有効にする必要があります。

## インストール方法

この拡張機能はChromeウェブストアには公開されていません。未パッケージの拡張機能として手動でインストールしてください。

1. このリポジトリをダウンロードまたはクローンする
2. Chromeで `chrome://extensions` を開く
3. 右上の**デベロッパーモード**を有効にする
4. **パッケージ化されていない拡張機能を読み込む**をクリックし、拡張機能のフォルダを選択する
5. ツールバーにKick Monitorのアイコンが表示される

---

## 使い方

1. 拡張機能のアイコンをクリックしてポップアップを開く
2. **配信者**タブで監視したいユーザー名を追加する
3. **設定**タブで各機能のオン／オフを切り替える
4. Kickの任意のチャンネルを開くと、チャット自動化が自動的に有効になる

ランダムエモートと定型文のタイマーは、配信者がオフラインになると自動的に停止し、配信再開時に再起動します。

---

## 設定一覧

| 設定項目 | デフォルト | 説明 |
|---|---|---|
| 🔴 配信開始時にタブを自動で開く | ✅ オン | 監視中の配信者が配信を開始するとタブを開く |
| 🔁 閉じたタブを再度開く | ✅ オン | 配信中のタブを閉じると再度開く |
| 🦜 オウムモード | ✅ オン | チャットのメッセージをランダムに繰り返す（確率15%、クールダウンあり） |
| 🏆 Wスパム検知 | ✅ オン | チャットでWスパムが流行ったときに自動参加する |
| 🎭 ランダムグローバルエモート | ✅ オン | 2〜5分おきにランダムなエモートを送信する |
| 💬 定型文を自動送信 | ❌ オフ | 登録した定型文を2〜5分おきに送信する |

設定はChromeのローカルストレージに保存され、セッションをまたいで維持されます。

---

## 必要な権限

| 権限 | 用途 |
|---|---|
| `storage` | 配信者リストと設定の保存 |
| `tabs` | 監視中のストリームのタブ操作 |
| `alarms` | バックグラウンドで1分ごとに配信状況をポーリング |
| `scripting` | Kickページへのコンテンツスクリプト注入 |
| `https://kick.com/*` | Kickページ上でのチャット読み取りとメッセージ送信 |

---

## 注意事項

- 拡張機能は `kick.com` のページ上でのみ動作します
- チャット自動化は配信者がオンラインの間のみ動作し、オフラインになるとすべてのタイマーが停止します
- オウムモードはページ読み込み後にメッセージが15件以上プールされるまで投稿しません
- チャットデータは外部に保存・送信されません
